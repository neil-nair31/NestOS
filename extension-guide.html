NestOS · Chrome helper install

Connect Naukri Resdex → NestOS

Recruiters keep working on Naukri. The NestOS helper captures shortlisted / visible CVs and sends them into NestOS Find on Naukri → Candidates.

Download Chrome extension (ZIP) Open Resdex test page Open NestOS

1. Download & unzip

  1. Click Download Chrome extension (ZIP) above
  2. Unzip the file — you should get a folder named nestos-naukri-helper that contains manifest.json

2. Load it in Chrome

  1. Open chrome://extensions
  2. Turn on Developer mode (top right)
  3. Click Load unpacked
  4. Select the unzipped nestos-naukri-helper folder (the one with manifest.json inside)
Chrome cannot install a ZIP directly — always unzip first, then Load unpacked.

3. Sign in (important)

  1. Click the NestOS extension icon in Chrome
  2. NestOS URL — paste the same NestOS link you use in the browser (for remote trial, use the public demo URL, not localhost)
  3. Sign in: recruiter@hummingbrains.com / Recruiter@123
If you see “Sign in via the NestOS helper popup first”, this step was skipped.

4. Capture CVs

  1. Practice (no Naukri login): open the Resdex test page → Scan → Send to NestOS
  2. Live: open Naukri recruiter login → Resdex → use the NestOS panel → Send to NestOS
  3. In NestOS: Find on Naukri — captures appear automatically. Click Save to NestOS or Save all

Note

Naukri does not provide a public API. This helper reads profiles already visible in your browser session after you search on Resdex — it does not log into Naukri for you or bypass CV credits.
