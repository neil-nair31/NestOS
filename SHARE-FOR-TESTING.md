## Role demo process (short)

### Recruiter (~15–20 min)
1. Login as recruiter → Home
2. **Candidates** → Add manually + upload a PDF
3. Install helper (ZIP) → popup NestOS URL = public base → sign in
4. **extension-demo** → Send to NestOS → **Find on Naukri** → Save
5. **Interviews** → open a pending card
6. **Log activity** → log a call/WhatsApp
7. **Messages & tasks** → send a note / check tasks

### Manager (~10–15 min)
1. Login as manager
2. **Interviews** — assign / schedule / open capture
3. **Team** + **Audit** — visibility
4. Skim **Clients / Leads / Revenue** + **Analytics**

### Sales (~10 min)
1. Login as sales
2. **Leads** — review Hot/Warm; convert one if useful
3. **Clients** — renewals & health
4. **Revenue** — MRR / invoice flow
5. Log a client call in **Activity**

### Admin (~10 min)
1. Login as admin
2. Walk the full left menu
3. **Settings** — users, video, ATS notes
4. Confirm lead → client → recruiter delivery loop
