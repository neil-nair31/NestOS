4. Role-by-role demo process

A. Recruiter — 15–20 minutes (start here)

Login recruiter@hummingbrains.com / Recruiter@123

Goal: prove “find people → keep them in NestOS → interview → prove outreach.”

  1. Home — KPIs for interviews needing you, Naukri captures, candidates, tasks. Click any KPI or “Do next”.
  2. Candidates
    • Add candidate manually → fill name/role/skills → Save → profile drawer opens.
    • Upload resume → drop/click PDF → NestOS parses text fields and adds/updates the person.
    • Open a row → try WhatsApp / Email / Share.
  3. Find on Naukri (core demo)
    • Download ZIP → unzip → Chrome Load unpacked → folder nestos-naukri-helper.
    • Extension popup: NestOS URL = public trial URL → sign in as recruiter.
    • Open Resdex practice page → Scan → Send to NestOS.
    • Back in NestOS → captures appear → Save / Save all → Candidates.
  4. Interviews — open a pending card; walk assign → schedule → capture → report.
  5. Log activity — log Call / WhatsApp with an outcome note.
  6. Messages & tasks — message a teammate; check tasks; try End day if shown.
  7. My numbers — pipeline / sourcing / outreach / interviews.

Useful for recruiters: one workspace instead of Naukri + folders + WhatsApp + Excel. Profiles stay with the firm. Outreach is provable.

B. Manager — 10–15 minutes

Login manager@hummingbrains.com / Manager@123

Goal: prove delivery control — interviews, team visibility, quality trail.

  1. Home — alerts, pending reports, quick links.
  2. Interviews — full IaaS board; New request; assign interviewer; open capture demo.
  3. Candidates / Find on Naukri — same tools as recruiters for oversight on mandates.
  4. Team — who is online / interviewing / on a call.
  5. Audit — immutable action log (ConnectOS-style verification flavour).
  6. Clients / Leads / Revenue — see what drives interview volume and retainers.
  7. Analytics — team scores, IaaS volume, report TAT.
  8. Assign a task from Messages (managers can assign).

Useful for managers: SLA and bottlenecks are visible before the client escalates. Less “status only in standup.”

C. Sales / Accounts — 10 minutes

Login sales@hummingbrains.com / Sales@123

Goal: prove growth → delivery handoff without recruiter clutter.

  1. Home — MRR, renewals soon, open leads.
  2. Leads — Hot / Warm / Cold enquiries; convert one to a client.
  3. Clients — health, renewal countdown, churn signal, last contact; open a row.
  4. Revenue — MRR / ARR / invoice path for billing conversations.
  5. Activity / Messages — log a client call so renewals aren’t only tribal knowledge.

Useful for sales: renewals and concentration risk surface early. Converted leads become recruiter work (mandates / IaaS) without re-typing.

D. Admin — 10 minutes

Login admin@hummingbrains.com / Admin@123

Goal: see the full firm operating picture + configuration.

  1. Walk the full left menu (everything managers + sales see).
  2. Settings — users/roles, Meet/Teams/Zoom, ATS connector concept, data ownership.
  3. Review recruiter End day / sign-out extras if pending.
  4. Trace the loop: Lead → Client → Mandate/IaaS → Candidates → Placement/Invoice.

Useful for leadership: one picture across Staff Aug, TA, and IaaS — not a spreadsheet per person.

6. Screen-by-screen — every option & why it matters

Home

Role-specific dashboard. KPIs are shortcuts into real work. Not a marketing collage.
Company value: each person lands on “what to do next,” not a blank ATS.

Candidates

  • Tabs — All / Staff Aug / Talent Acq / IaaS filters (aligns to HB service lines).
  • Upload resume(s) — PDF preferred; NestOS extracts name, skills, experience when text is readable.
  • Add candidate manually — create without a file; attach resume later in the drawer.
  • Row click → drawer — stage, source, CTC/notice, contact, skills, WhatsApp, Email, Verify doc, Share, Push to ATS (demo).
  • Match to open job — pick a requirement; ranked fits illustrate mandate matching.
Company value: every CV becomes a firm asset — searchable history, not “lost in Downloads.”

Find on Naukri

  • Download extension / Install guide — remote install pack for Mani’s team.
  • Refresh now — pull latest helper captures from NestOS.
  • Folders — Shortlist / Personal / Viewed / Emailed / All (mirrors Resdex habits).
  • Save / Save all — promote captures into Candidates.
  • Filter — keyword / location on the capture queue.
Company value: Naukri has no public API. Recruiters keep searching on Resdex; NestOS becomes the system of record. Fewer duplicate CV views, faster handoff to interviews.

Interviews (IaaS)

  • Kanban — New → Assigned → Scheduled → Needs notes → Delivered.
  • New request — client asks HB to interview on their behalf.
  • Card actions — Assign, Schedule (Meet/Teams/Zoom style link), Start/Continue capture, AI-assisted report, deliver to client.
Company value: scales Interview-as-a-Service without 45–60 min manual write-ups. Report TAT becomes a sales proof point.

Log activity

  • Buttons: Call / WhatsApp / Email / LinkedIn.
  • Filters by type; incomplete logs stay flagged.
  • Recruiters see their own trail; managers/admins see team.
Company value: ConnectOS discipline — if it isn’t logged, it doesn’t count in analytics.

Messages & tasks

Directory chat, attach/share resumes into threads, task list with due date & priority. Managers/admins can assign tasks; recruiters complete theirs.
Company value: stops “find that CV in WhatsApp from Tuesday.”

Analytics

Tabs for Pipeline, Sourcing, Outreach, Interviews / IaaS, plus Team & Leads for leadership. Built on verified activity, not verbal estimates.
Company value: same window language as ConnectOS — one place for performance conversations.

Clients

Services, MRR/fees, renewal countdown, health, churn flags, owner, last contact; click for detail.
Company value: renewals don’t slip unnoticed; MRR concentration risk is visible.

Leads

Website / referral enquiries. Hot / Warm / Cold. Convert → Client. Sales owns this; recruiters receive work after conversion.
Company value: inbound interest becomes pipeline with clear ownership.

Revenue

MRR / ARR / project / placement views and invoice workflow for trial billing discussions.
Company value: finance and delivery share one narrative — not separate trackers.

Team & Audit

Live people status; immutable action trail. Supports utilisation talks without micromanagement theatre.

Settings (Admin only)

Users & roles, video providers, ATS connector status, data retention / export posture (no lock-in).

7. Chrome Naukri helper — checklist

  1. Download ZIP: /downloads/nestos-naukri-helper.zip
  2. Unzip — folder must contain manifest.json
  3. Chrome → chrome://extensions → Developer mode ON → Load unpacked
  4. Select nestos-naukri-helper
  5. Popup → NestOS URL = public trial base → recruiter login
  6. Practice on /extension-demo, then real Naukri Resdex
  7. If you see “Sign in via the NestOS helper popup first” — open the extension icon and sign in (the page panel cannot log you in by itself)

8. End-to-end firm loop (what “good” looks like)

  1. Website enquiry lands in Leads (Sales).
  2. Sales converts → Client with service line (Staff Aug / TA / IaaS).
  3. Mandate or interview request appears for recruiting.
  4. Recruiter sources on Naukri → helper → Find on Naukri → Candidates.
  5. Outreach logged; shortlist shared in Messages.
  6. IaaS interview run → report delivered; or TA/Staff Aug stage moves forward.
  7. Invoice / retainer visible under Revenue; renewals watched on Clients.

9. Business outcomes NestOS is aiming at

  • Faster placements — shortlists and history live in one hub.
  • Lower Resdex waste — firm-owned profiles after first capture; less re-viewing the same CV.
  • Scalable IaaS — structured capture + fast reports protect margins on interview volume.
  • Account protection — renewal and churn signals before revenue walks out.
  • Manager visibility — verified activity instead of verbal stand-ups only.
  • Cleaner growth loop — website lead → sales → client → recruiter delivery.
  • Recruiter sanity — less tab-switching; work counts when logged.
