ConnectOS & NestOS — Plain-English Guide

What each product is, what each role does, and what every feature/screen is actually for. Written so you can explain it to Mani without jargon.

Start here — the 30-second picture

ConnectOS = the back office for a company website. When someone fills a form on connectorshr.com (job seeker, employer, contact), it lands in a secure admin inbox. That's it. No interviews, no Naukri, no recruiter pipeline.

NestOS = the full staffing company operating system for HummingBrains / RTS. Recruiters source candidates, run client interviews, log calls, get tasks, managers track team activity, sales handles clients and money. It's internal ops — not a public website.

HummingBrains business lines (why NestOS has so many modules)

RTS / HummingBrains sells three main services. NestOS modules map to these:

Business linePlain meaningNestOS modules involved
Staff Augmentation Client hires our people on contract (e.g. React dev on Trigo's team). We place engineers and they bill monthly. Talent Hub, Clients, Resdex, Activity log
Talent Acquisition (TA) Client pays a placement fee to hire someone permanently (e.g. find a CTO for NovaCart). One-time search + hire. Talent Hub, Leads → Clients, Resdex, Analytics pipeline
Interview-as-a-Service (IaaS) Client sends their candidates; we interview them and deliver a professional assessment report. Like outsourced technical interviewing. IaaS Operations, Team (interviewers), Audit, Workspace

Custom software projects (e.g. BlueOrbit) show in Revenue/Clients but are not the core staffing demo.

Part 1 — ConnectOS (ConnectorsHR)

Production product · website + admin

Public website (connectorshr.com)

What it is: Marketing site for ConnectorsHR recruitment brand.

What it does: Explains services; has forms so visitors can enquire.

Key pages:

  • Job Hunter — candidates upload CV + details (looking for a job).
  • For Employers — companies ask for hiring help (B2B lead).
  • Careers — people applying to work at ConnectorsHR.
  • Contact — general enquiry.

ConnectOS Forms send data to the API — not just email.

ConnectOS API (server)

What it is: Backend that receives form submissions, stores them in MySQL, handles CV file upload.

What it does: Validates input, blocks spam (honeypot), records which page the lead came from, can email sales (optional).

You don't demo this screen — it runs in the background.

ConnectOS Admin (/admin)

What it is: Password-protected inbox for everyone who submitted a form.

What it does:

  • List all submissions with type filter (candidate / employer / career / contact).
  • Search by name, email, company.
  • Open one submission → see full details + download CV.
  • Export CSV for Excel or CRM import.

Who uses it: ConnectorsHR owner / sales / ops — not the same as NestOS recruiter roles.

ConnectOS There is only one admin role in ConnectOS today (login user).

Part 3 — NestOS features (every screen explained)

Each module = one area of work

Home / Dashboard

Recruiter view ("Your day"): Shortcut cards — today's interview, Naukri queue, candidate count, tasks. Answer: "What should I do right now?"

Admin view: Platform KPIs — Resdex imports, ATS sync, phase status, import queue. Answer: "Is the machine working?"

Sales view: MRR, client count, hot leads, renewal warnings.

All roles Different content per role — same idea: morning briefing.

Talent Hub / All candidates

What it is: Central database of every person the company is tracking.

What it does: Store resume (PDF), parse skills into structured fields, see stage (Sourced → Screening → Interview → Offer), match to job requirements, push to client's ATS, share resume internally.

Real life: Replaces scattered folders + Excel. Once imported from Naukri or upload, the candidate stays forever as a company asset.

Recruiter, Manager, Admin

Find on Naukri (Resdex Sourcing)

What it is: Workflow helper for Naukri Resdex (paid CV database recruiters use daily).

What it does: Search/match candidates to open reqs, manage folders (Shortlist, Personal), track CV credits, block duplicate views (save money), one-click import into Talent Hub.

Real life: Today recruiters search Naukri in browser and save CVs locally. This brings shortlisted people into NestOS without re-buying the same CV.

Recruiter, Manager, Admin Demo simulates helper — not live Naukri API.

IaaS Operations / Run interviews

What it is: End-to-end workflow when a client asks HummingBrains to interview their candidate.

Steps in the system:

  1. Requested — client submits role + stack + candidate.
  2. Assigned — manager picks interviewer (AI suggests best match).
  3. Scheduled — date/time + auto Google Meet / Teams / Zoom link.
  4. Live capture — interviewer scores rubric during call (not from memory later).
  5. AI report — system writes formal assessment in ~2 minutes.
  6. Delivered — report sent to client; logged in audit.

Recruiter (if interviewer), Manager, Admin

Workspace / Messages & tasks

What it is: Internal team collaboration — like Slack + task list inside NestOS.

What it does: Message teammates, attach/share resumes (tracked in audit), see tasks assigned to you (due date, priority). Managers assign new tasks here or via bottom task bar.

Real life: Stops "check WhatsApp / email for that CV" — shares are logged.

All roles Recruiters see only their tasks; Admin/Manager see all + can assign.

Activity Log / Log calls & outreach

What it is: Diary of every touchpoint with candidates or clients.

What it does: Log Call, WhatsApp, Email, LinkedIn with who, why (REQ id), outcome. Marks Verified if complete; Incomplete if missing notes. Workspace messages also log here.

Why it matters: Managers can prove work happened. Unlogged work = zero credit in analytics (ConnectOS-style discipline).

All roles Recruiters must use daily; Admin sees everyone's log.

End day (sign-out)

What it is: End-of-shift form for recruiters/managers.

What it does: Shows auto-summary (logs, tasks, interviews today). User adds extra work they forgot to log → submits → Admin gets notified to review and optionally backfill activity.

Recruiter, Manager submit Admin reviews

Task command bar (bottom of screen)

What it is: Sticky bar for Admin/Manager only.

What it does: Shows open assigned tasks across team; quick "Assign task" without hunting menus.

Admin, Manager only

Analytics / My analytics

What it is: Charts and numbers — one window for business intelligence.

Tabs:

  • Pipeline — how many candidates at each stage (Sourced → Placed).
  • Sourcing — Resdex vs upload vs referral; CV credits saved.
  • Outreach — calls, messages, emails per week (from activity log).
  • Team — utilization scores, sign-out compliance.
  • IaaS — interview volume, report turnaround time.
  • Leads — website enquiry funnel (sales).

Recruiter sees own-scoped view. Admin/Manager/Sales see firm-wide.

Clients

What it is: CRM for paying companies (Trigo, Kredmint, Vantara, etc.).

What it does: Account health score, MRR, renewal date, services (Staff Aug / IaaS / TA), owner, notes, churn warnings. Click client → history + interviews linked.

Sales, Manager, Admin Recruiters don't need this daily.

Leads

What it is: Pre-client enquiries — companies that contacted HummingBrains but aren't customers yet.

What it does: Hot/warm/cold scoring, source (website, LinkedIn, referral), status (New → Contacted → Converted). Convert button creates a Client record.

Not the same as: Talent Hub candidates (people looking for jobs). Leads = companies looking for staffing help.

Sales, Manager, Admin

Revenue

What it is: Money dashboard — not accounting/payroll.

What it does: MRR, ARR, revenue by line (Staff Aug, IaaS, placement fees, projects), trends, concentration risk (e.g. one client = 30% of MRR).

Sales, Manager, Admin

Team & Live Tracking

What it is: Live view of what each employee is doing right now.

What it does: Status (online, in interview, on call, away), current task label, hours today, sessions. Monthly reports per person (interviews, placements, validation flags).

Manager, Admin

Audit & Compliance

What it is: Immutable log of system events + idle detection.

What it does: Records who did what, when, for how long. Flags idle blocks (>8 min no activity). Export for compliance (DPDP). Principle: verified activity only counts toward scores.

Manager, Admin

Settings

What it is: Platform configuration (Admin only).

What it does: User roles list, video meeting connectors (Meet/Teams/Zoom), ATS two-way sync (Greenhouse, Workday), module phase status, data retention policy.

Admin only
